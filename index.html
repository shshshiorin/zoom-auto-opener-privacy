プライバシーポリシー

対象：ブラウザ拡張機能「Zoom Auto Opener for Google Calendar」
最終更新日：2026年7月14日

本拡張機能（以下「本拡張」）は、Googleカレンダーの予定を確認し、予定の開始前に、その予定に記載されたZoomミーティングのURLを自動的に開くことを目的としています。本ポリシーは、本拡張が取り扱う情報とその利用方法を説明するものです。

1. 基本方針

  • 本拡張のすべての処理は、お使いの端末（ブラウザ）内で完結します。
  • 開発者が運用するサーバーは存在せず、あなたのカレンダー情報や個人情報を開発者または第三者に送信・保存することは一切ありません。
  • 広告、トラッキング、アクセス解析などのツールは使用していません。

2. 取得・利用する情報

  • Googleカレンダーのデータ（読み取り専用）：calendar.readonly 権限により、予定の開始時刻・タイトル・場所・説明・会議情報を読み取ります。これは、予定内のZoomリンクを検出し、開くタイミングを判定するためだけに使用します。予定の内容を変更・作成・削除することはありません。
  • 認証情報：Chromeの Identity API を通じて、あなた自身のGoogleアカウントのOAuthアクセストークンを取得し、Google Calendar API の呼び出しに使用します。トークンはChrome／Googleが管理し、本拡張が独自に保存することはありません。
  • 設定および動作記録：「開始何分前に開くか」などの設定と、同じ予定を二重に開かないための処理済み記録を、ブラウザの chrome.storage に保存します。設定はChromeの同期機能により、あなたのGoogleアカウントに紐づく端末間で同期される場合があります。

3. データの保存場所と通信

  • カレンダーデータの取得は、あなたのブラウザからGoogleの公式API（googleapis.com）へ直接HTTPS通信する形でのみ行われます。
  • 取得したデータは処理のために一時的にメモリ上で扱われるのみで、外部へ送信されません。
  • 設定・処理済み記録は、あなたのブラウザ内（chrome.storage）にのみ保存されます。

4. 第三者への提供

本拡張は、取得したいかなる情報も第三者に販売・譲渡・提供しません。

5. Google ユーザーデータの限定利用（Limited Use）

本拡張によるGoogleユーザーデータの取得・利用・転送は、Limited Use要件を含む Google API Services User Data Policy に準拠します。データは、上記の機能を提供する目的以外には使用しません。

6. データの保持と削除

  • 処理済み記録は約6時間後に自動的に削除されます。
  • 設定および記録は、本拡張をアンインストールするか、Chromeの拡張データを消去することで削除されます。
  • Googleアカウントへのアクセス許可は、 Googleアカウントのサードパーティアクセス設定 からいつでも取り消せます。

7. セキュリティ

外部との通信はGoogle公式APIへのHTTPS通信に限られます。本拡張は外部サーバーへデータを送信しないため、通信経路上での情報流出のリスクを最小化しています。

8. 本ポリシーの変更

本ポリシーは必要に応じて改定することがあります。変更があった場合は、本ページを更新します。
